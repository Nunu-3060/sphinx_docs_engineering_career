2. 記憶と学習の仕組み

本章では、学習の土台となる記憶の仕組みを説明する。記憶がどのような要素から成り立っているのか、情報がどのように覚えられ、保たれ、思い出されるのかを理解しておくと、後の章で紹介する学習法がなぜ効くのかが分かりやすくなる。

2.1. 学習とは何か

心理学では、学習を「経験によって生じる、比較的長く続く行動や知識の変化」と定義することが多い。この定義には 2 つの要点がある。

1 つ目は「経験によって」という点である。成長や疲労による変化は学習に含めない。2 つ目は「比較的長く続く」という点である。直前に読んだ内容を一時的に答えられることと、数週間後にも答えられることは区別される。

この 2 つ目の点は、独学にとって特に重要である。学習の最中にうまくできていることを「パフォーマンス（遂行）」、後になっても残っている変化を「学習」と呼び分けることがある（Soderstrom と Bjork, 2015）。学習中のパフォーマンスが高くても、学習が成立しているとは限らない。逆に、学習中に苦労して成績が低くても、後に残る学習は大きいことがある。この区別は第 5 章の「望ましい困難」で詳しく扱う。

2.2. 記憶のモデル

記憶の仕組みを説明するモデルとして古くから知られているのが、Atkinson と Shiffrin（1968）の多重貯蔵モデルである。このモデルでは、記憶を以下の 3 つの貯蔵庫に分けて考える（図 2.1）。

表 2.1 多重貯蔵モデルの 3 つの貯蔵庫

貯蔵庫

役割

特徴

感覚記憶

目や耳から入った情報をごく短時間保持する。

容量は大きいが、保持時間は 1 秒前後（聴覚では数秒）と短い。注意を向けた情報だけが次の段階に送られる。

短期記憶（作業記憶）

意識している情報を一時的に保持し、処理する。

容量が小さく、繰り返さなければ数十秒で失われる。

長期記憶

知識や経験を長期間保持する。

容量に実用上の限界はなく、数十年保持されることもある。

このモデルは記憶の全体像をつかむのに便利だが、現在では単純化しすぎていると考えられている。例えば、短期記憶は単なる一時置き場ではなく、情報を操作する作業場でもあること（次の節）、長期記憶にはいくつもの種類があること（その次の節）が分かっている。また、情報を繰り返し唱えるだけ（単純なリハーサル）では、長期記憶にはあまり残らないことも分かっている。

2.3. 作業記憶

作業記憶（working memory）は、情報を一時的に保持しながら、同時にそれを操作するための仕組みである。暗算をする、文章を読んで意味を理解する、問題の解き方を考えるといった知的な活動のほとんどは、作業記憶の中で行われる。

Baddeley と Hitch（1974）が提案し、その後 Baddeley（2000）が拡張した作業記憶のモデルは、以下の要素から成る（図 2.2）。

  • 中央実行系：注意を配分し、他の要素を制御する。

  • 音韻ループ：言葉や音の情報を保持する。頭の中で唱えることで保持時間を延ばせる。

  • 視空間スケッチパッド：視覚的な情報や位置の情報を保持する。

  • エピソード・バッファ：複数の種類の情報や長期記憶の情報を統合して保持する。

作業記憶の最も重要な性質は、容量が小さいことである。Miller（1956）は、人が一度に保持できる項目の数を「7 ± 2」と見積もった。この数字は広く知られているが、後の研究では、項目をまとめたり唱えたりする工夫を防いだ条件では、実際の容量は「4 程度」であるという見方が有力になっている（Cowan, 2001）。

いずれにしても、作業記憶に同時に置いておける情報はごくわずかである。新しいことを学ぶときに混乱するのは、多くの場合、作業記憶の容量を超える情報を一度に処理しようとしているためである。この点は第 3 章の認知負荷理論で詳しく扱う。

ただし、作業記憶の容量の限界は、長期記憶にある知識によって実質的に広げられる。例えば「NHKJRUSA」という 8 文字の列は、初めて見る文字の並びとしては覚えにくいが、「NHK」「JR」「USA」という知っている 3 つの単位として見れば容易に覚えられる。このように、知識を使って情報をまとまりにすることをチャンキングと呼ぶ。チャンキングも第 3 章で扱う。

2.4. 長期記憶の種類

長期記憶は、意識して思い出せるかどうかによって、大きく 2 種類に分けられる。

学習の目標によって、主に鍛えるべき記憶は異なる。用語や事実を覚えることは主に意味記憶の学習であり、楽器の演奏やプログラムを書く手際は主に手続き的記憶の学習である。実際の学習では両者が組み合わさっている。例えばプログラミングでは、言語の文法（意味記憶）と、エラーを見て原因を探る手順（手続き的記憶）の両方が必要になる。手続き的記憶を伸ばす方法は第 8 章で扱う。

2.5. 符号化・貯蔵・検索

記憶の働きは、以下の 3 つの段階に分けて考えることができる。

  • 符号化：情報を記憶に取り込む段階。

  • 貯蔵：情報を記憶に保つ段階。

  • 検索：記憶から情報を取り出す段階。

「覚えられない」という悩みは、どの段階でつまずいているかによって対策が変わる。

2.5.1. 符号化と処理水準

Craik と Lockhart（1972）は、情報がどれだけ記憶に残るかは、その情報をどれだけ深く処理したかによって決まると考えた（処理水準説）。例えば単語を覚えるとき、文字の形（大文字か小文字か）に注目するよりも、音（何と韻を踏むか）に注目するほうがよく残り、さらに意味（どんな文に当てはまるか）を考えるほうがよく残る。

独学に当てはめると、文章を目で追うだけの「浅い」処理よりも、内容の意味を考え、既に知っていることと結びつけ、自分の言葉で言い換える「深い」処理のほうが記憶に残りやすい。第 5 章の精緻化質問や自己説明は、深い処理を促す方法である。

2.5.2. 検索と検索手がかり

記憶に貯蔵されていても、取り出せなければ使えない。「喉まで出かかっているのに思い出せない」という経験は、貯蔵されている情報を検索できない状態の例である。

検索を助けるのが検索手がかりである。手がかりとなるのは、関連する知識だけではない。覚えたときの場所や状況も手がかりになる。Godden と Baddeley（1975）は、ダイバーに水中または陸上で単語を覚えさせ、水中または陸上で思い出させる実験を行った。その結果、覚えたときと同じ環境で思い出すほうが成績がよかった。これを文脈依存記憶と呼ぶ。

ただし、この結果から「試験会場と同じ環境で勉強すべきだ」と考えるのは早計である。現実の学習で問題になるのは、むしろ特定の環境や手がかりがないと思い出せない知識になってしまうことである。複数の場所や状況で学ぶと、特定の文脈に依存しにくい知識になると考えられている（Smith ら, 1978）。

検索は、記憶を取り出すだけの行為ではない。思い出すこと自体が記憶を強める。この性質を利用した学習法が第 5 章の検索練習である。

2.6. スキーマと既有知識

スキーマとは、長期記憶の中にある、ある事柄についての知識の枠組みである。例えば「レストランで食事をする」というスキーマには、入店する、席に案内される、注文する、食べる、支払うといった典型的な流れが含まれている。

スキーマは、新しい情報の理解と記憶を大きく助ける。Bransford と Johnson（1972）は、何について書かれているかが分からない抽象的な文章を参加者に読ませる実験を行った。文章の前に「これは洗濯の手順についての文章である」という題名を示された参加者は、示されなかった参加者よりも、文章をよく理解し、よく覚えていた。題名によって適切なスキーマが呼び出され、文章の各部分をそこに位置づけられたためである。

この知見から、独学について以下のことが言える。

  • 既に知っていることが多い分野ほど、新しいことを覚えやすい。知識は知識を呼ぶ。

  • 新しい分野を学ぶときは、最初に全体像（目次、概要、地図）をつかむと、細部を位置づけやすくなる。

  • 初心者のうちは学習の効率が低く感じられるが、基礎知識が増えるにつれて効率は上がっていく。

逆に言えば、ある分野の基礎を飛ばして応用から始めると、新しい情報を位置づける枠組みがないため、理解も記憶も難しくなる。

2.7. 記憶の固定化と睡眠

学習した直後の記憶は不安定であり、時間をかけて安定した形に変わっていく。この過程を記憶の固定化（consolidation）と呼ぶ。

固定化には睡眠が重要な役割を果たすことが、多くの研究で示されている（Diekelmann と Born, 2010）。睡眠中に、その日に学習した内容の神経活動が再生され、記憶が強められたり、既存の知識と統合されたりすると考えられている。また、学習の前の睡眠不足は、新しい情報を記憶に取り込む力を低下させる（Yoo ら, 2007）。

エビデンスの強さ：強い（睡眠が記憶の固定化に関わること）

睡眠と学習の関係の具体的な活かし方は第 11 章で扱う。ここでは、睡眠時間を削って勉強時間を増やすことは、覚えた内容の定着を妨げ、翌日の学習の効率も下げるので、得策ではないことを指摘しておく。

2.8. 神経可塑性の概要

学習によって脳の構造や働きが変わることを、神経可塑性と呼ぶ。学習すると、神経細胞どうしのつながり（シナプス）が強まったり、新しくできたりする。

神経可塑性は成人になっても失われない。例えば Maguire ら（2000）は、ロンドンの複雑な道路網を覚えたタクシー運転手は、そうでない人に比べて、空間の記憶に関わる海馬の後部が大きいことを報告した。また、運転手としての経験が長いほど、その部分が大きい傾向があった。

エビデンスの強さ：強い（成人の脳も学習によって変化すること）

一方で、「脳を鍛える」とうたうゲームやアプリ（脳トレ）については、評価が分かれている。Simons ら（2016）による大規模なレビューは、脳トレで練習した課題そのものの成績は向上するが、練習していない課題や日常生活の能力が向上するという証拠はほとんどないと結論づけた。

エビデンスの強さ：弱い（脳トレで一般的な知的能力が向上すること）

独学にとっての教訓は、「脳を鍛えてから学ぶ」のではなく、「学びたいことを直接学ぶ」のが近道だということである。何かを学べば、その分野についての脳は確かに変わる。しかし、その変化が無関係な分野にまで広がることは期待しにくい。この点は第 7 章の転移の節でも扱う。

2.9. この章のまとめ

  • 学習中のパフォーマンス（その場でできること）と、後に残る学習は区別する必要がある。

  • 作業記憶の容量はごく小さく（4 程度という見方が有力）、新しいことを学ぶときの制約になる。

  • 長期記憶には、宣言的記憶（エピソード記憶、意味記憶）と手続き的記憶がある。

  • 情報は、意味を考えて深く処理するほど記憶に残りやすい。

  • 思い出すこと（検索）自体が記憶を強める。

  • 既有知識（スキーマ）は新しい情報の理解と記憶を助ける。全体像を先につかむとよい。

  • 睡眠は記憶の固定化に重要である。

  • 脳は学習によって変わるが、脳トレの効果が他の能力に広がる証拠は乏しい。

2.10. やってみよう

  1. 今日学んだことを、本を閉じた状態で 3 つ書き出す。書き出せなかったものは、どの段階（符号化、貯蔵、検索）でつまずいたと考えられるかを考える。

  2. 次に学ぶ単元の目次や概要を先に読み、全体像を 1 枚の紙に図として描いてから本文を読む。描かなかったときと比べて、読みやすさがどう変わったかを記録する。

  3. 1 週間、毎晩の睡眠時間と、翌日の学習の調子（集中できたか、前日の内容を覚えていたか）を記録し、関係があるかを見る。
