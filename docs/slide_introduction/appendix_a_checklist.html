付録 A チェックリスト

本編の内容を、発表の準備の段階ごとのチェックリストにまとめた。括弧内は、詳しい説明のある章である。

準備（スライドを作る前）

  • [ ] 発表のゴールを、聞き手の状態や行動で書いた（3 章）

  • [ ] 聞き手の立場、前提知識、関心事、意思決定権を確認した（3 章）

  • [ ] 持ち時間、質疑応答の時間、会場、機材、資料の扱いを確認した（3 章）

  • [ ] キーメッセージを、主張のある 1 文で書いた（3 章）

  • [ ] キーメッセージを支える根拠を 3 つ前後に整理した（4 章）

  • [ ] 構成の型を選び、テキストでアウトラインを作った（4 章）

  • [ ] 区切りごとの時間配分を決めた（4 章）

スライドの作成

構成

  • [ ] 冒頭で結論（キーメッセージ）を示している（4 章）

  • [ ] 各スライドのタイトルがアクションタイトルになっている（4 章）

  • [ ] タイトルだけを順に読んで、話が通る（4 章）

  • [ ] ゴールに不要なスライドがない。詳細は付録に回した（4 章）

  • [ ] 最後にまとめのスライドがあり、キーメッセージを繰り返している（4 章、12 章）

デザイン

  • [ ] 1 枚のスライドで伝えるメッセージは 1 つである（5 章）

  • [ ] 関係のある要素が近くにまとまっている（近接、5 章）

  • [ ] 要素の端がそろっている（整列、5 章）

  • [ ] タイトルの位置・大きさ・色が全スライドで統一されている（反復、5 章）

  • [ ] 強調は 1 枚に 1〜2 か所で、はっきり目立っている（コントラスト、5 章）

  • [ ] 本文は 24 pt 以上、最小の文字も 18 pt 以上である（5 章）

  • [ ] 色はベースカラー、メインカラー、アクセントカラーを基本にしている（5 章）

  • [ ] 文字と背景のコントラスト比が十分である（5 章）

  • [ ] 色だけで情報を区別していない（5 章）

  • [ ] 使うフォントは 2〜3 種類までで、発表する環境に入っている（5 章）

図表

  • [ ] 関係のある項目は、箇条書きではなく図解にした（6 章）

  • [ ] グラフのタイトルが、読み取ってほしいメッセージになっている（6 章）

  • [ ] グラフの不要な要素（凡例、格子線、3D）を減らし、伝えたい点を強調した（6 章）

  • [ ] 表の行と列を絞り、注目してほしい数値を強調した（6 章）

  • [ ] コードは 10 行程度までで、18 pt 以上の文字にした（6 章）

  • [ ] 画像の権利を確認した。スクリーンショットに機密情報が写り込んでいない（6 章）

  • [ ] アニメーションは、話の順に要素を表示する目的だけに使っている（6 章）

発表の直前

  • [ ] 声に出して通しのリハーサルを行い、時間を測った（8 章）

  • [ ] 時間が押したときに削る部分を決めた（8 章、9 章）

  • [ ] 冒頭の数文とまとめを覚えた（8 章、9 章）

  • [ ] 発表者ノートを、短い箇条書きで書いた（8 章）

  • [ ] 想定質問の答えと、予備のスライドを用意した（8 章）

  • [ ] 接続端子、画面の縦横比、発表者ツールの表示を確認した（8 章）

  • [ ] スライドの PDF を、予備として別の場所に置いた（8 章）

  • [ ] 通知を止めた（8 章、11 章）

  • [ ] オンラインの場合: マイク、カメラ、共有するウィンドウを確認した（11 章）

発表の後

  • [ ] ゴールを達成できたかを振り返った（12 章）

  • [ ] 時間の過不足と、延びた箇所を記録した（12 章）

  • [ ] 出た質問を記録した。持ち帰った質問に回答した（10 章、12 章）

  • [ ] 修正を反映した最終版の資料を保存した（12 章）
