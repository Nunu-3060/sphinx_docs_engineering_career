本書のサンプルコードを示す。いずれも Python 3.10 以降で動作し、標準ライブラリと matplotlib だけを使う。生成 AI などの外部サービスは呼び出さない。

実行の準備

matplotlib を使うサンプル（forgetting_curve.py と study_log.py）を実行するには、matplotlib をインストールしておく。

1py -m pip install matplotlib

コマンド例は Windows の py コマンドで示す。macOS や Linux では python3 に読み替える。Windows のコマンドプロンプトで日本語の出力が文字化けする場合は、環境変数 PYTHONIOENCODING に utf-8 を設定する。

グラフを出力するサンプルは、サンプルと同じフォルダに output フォルダを作成し、その中に PNG ファイルを保存する。

コードの検査

サンプルコードには型ヒントを付け、flake8 と mypy（strict モード）で検査している。設定は examples フォルダの setup.cfg に記述した（setup.cfg）。examples フォルダで次のコマンドを実行すると検査できる。

1py -m pip install flake8 mypy
2py -m flake8 .
3py -m mypy .

forgetting_curve.py

忘却曲線と、間隔を空けて復習したときの保持率の変化を、簡易モデルで計算する。モデルの考え方は 第 16 章 学習を支える仕組みとツール で説明する。

forgetting_curve.py

コード 27 forgetting_curve.py
  1"""忘却曲線と復習の効果を簡易モデルで計算し、グラフにする。
  2
  3使い方:
  4    py forgetting_curve.py                      # 1, 3, 7, 14 日目に復習する例
  5    py forgetting_curve.py --reviews 2 5 12     # 復習日を指定する
  6    py forgetting_curve.py --reviews            # 復習しない場合
  7
  8結果は表として画面に表示し、グラフを output/forgetting_curve.png に保存する。
  9
 10モデル:
 11    保持率 R(t) = 1 / (1 + t / (9 * S))
 12        t: 最後の学習からの経過日数
 13        S: 安定性（保持率が 0.9 まで下がるのにかかる日数）
 14    復習すると安定性 S は BASE_GAIN + GAIN * (1 - R) 倍になる。
 15    R は復習した時点の保持率で、思い出しにくくなってから復習するほど安定性が大きく伸びる。
 16
 17これは仕組みを理解するための簡易モデルであり、実際の記憶を正確に予測するものではない。
 18"""
 19
 20from __future__ import annotations
 21
 22import argparse
 23import pathlib
 24
 25import matplotlib
 26
 27matplotlib.use("Agg")
 28
 29import matplotlib.pyplot as plt  # noqa: E402
 30
 31INITIAL_STABILITY = 1.0  # 初回学習後の安定性（日）
 32BASE_GAIN = 1.3  # 復習による安定性の伸び（最小値）
 33GAIN = 8.0  # 思い出しにくさに応じた安定性の伸び
 34OUTPUT_DIR = pathlib.Path(__file__).resolve().parent / "output"
 35
 36
 37def retention(elapsed: float, stability: float) -> float:
 38    """最後の学習から elapsed 日後の保持率を返す。"""
 39    return 1.0 / (1.0 + elapsed / (9.0 * stability))
 40
 41
 42def simulate(review_days: list[float], end_day: float, step: float = 0.05) -> tuple[list[float], list[float]]:
 43    """0 日目に初めて学習し、review_days に復習したときの保持率の推移を返す。
 44
 45    戻り値は (経過日数のリスト, 保持率のリスト) である。
 46    """
 47    days: list[float] = []
 48    values: list[float] = []
 49    reviews = sorted(review_days)
 50    stability = INITIAL_STABILITY
 51    last_study = 0.0
 52    next_index = 0
 53    n_steps = int(end_day / step)
 54    for i in range(n_steps + 1):
 55        day = i * step
 56        # この時点までに予定されている復習をすべて反映する。
 57        while next_index < len(reviews) and reviews[next_index] <= day:
 58            review_day = reviews[next_index]
 59            recall = retention(review_day - last_study, stability)
 60            stability *= BASE_GAIN + GAIN * (1.0 - recall)
 61            last_study = review_day
 62            next_index += 1
 63        days.append(day)
 64        values.append(retention(day - last_study, stability))
 65    return days, values
 66
 67
 68def retention_before(review_days: list[float], target: float) -> float:
 69    """target 日目の保持率を返す。
 70
 71    target 日目に復習する場合は、その復習をする直前の値を返す。
 72    """
 73    stability = INITIAL_STABILITY
 74    last_study = 0.0
 75    for review_day in sorted(review_days):
 76        if review_day >= target:
 77            break
 78        recall = retention(review_day - last_study, stability)
 79        stability *= BASE_GAIN + GAIN * (1.0 - recall)
 80        last_study = review_day
 81    return retention(target - last_study, stability)
 82
 83
 84def main() -> None:
 85    parser = argparse.ArgumentParser(description="忘却曲線と復習の効果を簡易モデルで計算する。")
 86    parser.add_argument("--reviews", type=float, nargs="*", default=[1.0, 3.0, 7.0, 14.0], help="復習する日（初回学習からの経過日数）")
 87    parser.add_argument("--days", type=float, default=30.0, help="計算する日数")
 88    args = parser.parse_args()
 89
 90    reviews: list[float] = args.reviews
 91    end_day: float = args.days
 92
 93    base_days, base_values = simulate([], end_day)
 94    days, values = simulate(reviews, end_day)
 95
 96    print(f"復習日: {reviews if reviews else 'なし'}")
 97    # 全角文字は半角 2 文字分の幅で表示されるため、見出しは空白で位置を合わせる。
 98    print("経過日数 復習しない   復習する（復習日は復習直前の値）")
 99    for check_day in [2, 5, 10, 20, 30]:
100        if check_day > end_day:
101            break
102        no_review = retention_before([], check_day)
103        with_review = retention_before(reviews, check_day)
104        print(f"{check_day:>8} {no_review:>10.2f} {with_review:>10.2f}")
105
106    OUTPUT_DIR.mkdir(exist_ok=True)
107    fig, ax = plt.subplots(figsize=(7.0, 4.0))
108    ax.plot(base_days, base_values, linestyle="--", label="no review")
109    ax.plot(days, values, label=f"review on days {reviews}")
110    ax.set_xlabel("days since first study")
111    ax.set_ylabel("retention (model)")
112    ax.set_ylim(0.0, 1.05)
113    ax.grid(True, alpha=0.3)
114    ax.legend(loc="lower left")
115    fig.tight_layout()
116    path = OUTPUT_DIR / "forgetting_curve.png"
117    fig.savefig(path, dpi=100)
118    plt.close(fig)
119    print(f"グラフを保存した: {path}")
120
121
122if __name__ == "__main__":
123    main()

コード 28 leitner_box.py
 1"""ライトナー方式によるカード管理をシミュレーションする。
 2
 3ライトナー方式では、カードを複数の箱に分けて管理する。
 4
 5* 新しいカードは箱 1 に入れる。
 6* 箱 k のカードは 2 ** (k - 1) 日ごとに復習する（箱 1 は毎日、箱 2 は 2 日ごと、…）。
 7* 正解したカードは一つ上の箱へ移す（最上位の箱ではそのまま）。
 8* 不正解だったカードは箱 1 に戻す。
 9
10正解する確率は、箱が上がるほど高くなるように仮定した簡易モデルで決める。
11実際の記憶を予測するものではなく、カードが箱の間を移動する様子を見るためのものである。
12
13使い方:
14    py leitner_box.py                    # 30 枚のカードを 30 日間シミュレーションする
15    py leitner_box.py --cards 50 --days 60 --seed 1
16"""
17
18from __future__ import annotations
19
20import argparse
21import random
22from dataclasses import dataclass
23
24NUM_BOXES = 5
25# 各箱のカードに正解する確率（仮定）。箱が上がるほど定着していると考える。
26CORRECT_PROBABILITY = {1: 0.6, 2: 0.75, 3: 0.85, 4: 0.9, 5: 0.95}
27
28
29@dataclass
30class Card:
31    """1 枚のカード。"""
32
33    card_id: int
34    box: int = 1
35
36
37def review_interval(box: int) -> int:
38    """箱 box のカードを復習する間隔（日）を返す。"""
39    return int(2 ** (box - 1))
40
41
42def is_due(box: int, day: int) -> bool:
43    """day 日目が箱 box の復習日かどうかを返す。"""
44    return day % review_interval(box) == 0
45
46
47def run_day(cards: list[Card], day: int, rng: random.Random) -> tuple[int, int]:
48    """day 日目の復習を行い、(復習した枚数, 正解した枚数) を返す。"""
49    reviewed = 0
50    correct = 0
51    for card in cards:
52        if not is_due(card.box, day):
53            continue
54        reviewed += 1
55        if rng.random() < CORRECT_PROBABILITY[card.box]:
56            correct += 1
57            card.box = min(card.box + 1, NUM_BOXES)
58        else:
59            card.box = 1
60    return reviewed, correct
61
62
63def box_counts(cards: list[Card]) -> list[int]:
64    """箱ごとのカード枚数を返す。"""
65    counts = [0] * NUM_BOXES
66    for card in cards:
67        counts[card.box - 1] += 1
68    return counts
69
70
71def main() -> None:
72    parser = argparse.ArgumentParser(description="ライトナー方式をシミュレーションする。")
73    parser.add_argument("--cards", type=int, default=30, help="カードの枚数")
74    parser.add_argument("--days", type=int, default=30, help="シミュレーションする日数")
75    parser.add_argument("--seed", type=int, default=0, help="乱数の種（同じ値なら同じ結果になる）")
76    args = parser.parse_args()
77
78    rng = random.Random(args.seed)
79    cards = [Card(card_id=i) for i in range(args.cards)]
80
81    # 全角文字は半角 2 文字分の幅で表示されるため、見出しは空白で位置を合わせる。
82    header = " ".join(f"箱{b}" for b in range(1, NUM_BOXES + 1))
83    print(f" 日 復習 正解  {header}")
84    total_reviews = 0
85    for day in range(args.days):
86        reviewed, correct = run_day(cards, day, rng)
87        total_reviews += reviewed
88        counts = " ".join(f"{c:>3}" for c in box_counts(cards))
89        print(f"{day:>3} {reviewed:>4} {correct:>4}  {counts}")
90
91    print(f"復習した延べ枚数: {total_reviews}（毎日すべてのカードを復習すると {args.cards * args.days}）")
92
93
94if __name__ == "__main__":
95    main()

sm2_scheduler.py

SM-2 アルゴリズムで、復習ごとの自己評価（0 から 5）から次回の復習日を計算する。

sm2_scheduler.py

コード 29 sm2_scheduler.py
 1"""SM-2 アルゴリズムで次回の復習日を計算する。
 2
 3SM-2 は 1980 年代に P. A. Wozniak が SuperMemo のために考案したアルゴリズムで、
 4多くの間隔反復ソフトの基礎になっている。復習のたびに、思い出せた度合いを
 50 から 5 の 6 段階で自己評価し、その値から次回の復習間隔を決める。
 6
 7    5: 完璧に思い出せた
 8    4: 少し迷ったが思い出せた
 9    3: かなり苦労して思い出せた
10    2: 思い出せなかったが、答えを見ると簡単に感じた
11    1: 思い出せなかったが、答えを見て思い出した
12    0: まったく思い出せなかった
13
14使い方:
15    py sm2_scheduler.py 5 4 3 5 2 4    # 復習ごとの自己評価を順に与える
16    py sm2_scheduler.py --start 2026-11-01 5 5 5
17"""
18
19from __future__ import annotations
20
21import argparse
22import datetime
23from dataclasses import dataclass
24
25MIN_EASINESS = 1.3
26
27
28@dataclass(frozen=True)
29class CardState:
30    """カードの学習状態。"""
31
32    repetition: int = 0  # 連続して正解した回数
33    interval: int = 0  # 次回までの間隔（日）
34    easiness: float = 2.5  # 易しさ係数（E-Factor）
35
36
37def update_easiness(easiness: float, quality: int) -> float:
38    """自己評価 quality に応じて易しさ係数を更新する。"""
39    new_value = easiness + (0.1 - (5 - quality) * (0.08 + (5 - quality) * 0.02))
40    return max(MIN_EASINESS, new_value)
41
42
43def review(state: CardState, quality: int) -> CardState:
44    """自己評価 quality で復習した後の状態を返す。"""
45    if not 0 <= quality <= 5:
46        raise ValueError(f"自己評価は 0 から 5 の整数で指定する: {quality}")
47
48    easiness = update_easiness(state.easiness, quality)
49    if quality < 3:
50        # 思い出せなかった場合は、最初から覚え直す。
51        return CardState(repetition=0, interval=1, easiness=easiness)
52
53    repetition = state.repetition + 1
54    if repetition == 1:
55        interval = 1
56    elif repetition == 2:
57        interval = 6
58    else:
59        interval = round(state.interval * easiness)
60    return CardState(repetition=repetition, interval=interval, easiness=easiness)
61
62
63def main() -> None:
64    parser = argparse.ArgumentParser(description="SM-2 アルゴリズムで次回の復習日を計算する。")
65    parser.add_argument("qualities", type=int, nargs="+", help="復習ごとの自己評価（0 から 5）")
66    parser.add_argument(
67        "--start", type=datetime.date.fromisoformat, default=datetime.date.today(), help="初回学習日（YYYY-MM-DD）"
68    )
69    args = parser.parse_args()
70
71    qualities: list[int] = args.qualities
72    day: datetime.date = args.start
73    state = CardState()
74
75    print("回 学習日       評価 易しさ 間隔 次回")
76    for count, quality in enumerate(qualities, start=1):
77        state = review(state, quality)
78        next_day = day + datetime.timedelta(days=state.interval)
79        print(f"{count:>2} {day} {quality:>4} {state.easiness:>6.2f} {state.interval:>4} {next_day}")
80        day = next_day
81
82
83if __name__ == "__main__":
84    main()

 7CSV の形式（1 行目は見出し）:
 8    question,answer

16from __future__ import annotations
17
18import argparse

21import random
22from dataclasses import dataclass

35def load_questions(path: pathlib.Path) -> list[Question]:
36    """CSV ファイルから問題を読み込む。"""
37    with path.open(encoding="utf-8", newline="") as f:
38        reader = csv.DictReader(f)
39        return [Question(row["question"], row["answer"]) for row in reader]

42def ask(item: Question, number: int, total: int) -> bool:
43    """1 問出題し、思い出せたら True を返す。"""
44    print(f"\n[{number}/{total}] {item.question}")
45    input("  答えを思い出したら Enter キーを押す...")
46    print(f"  答え: {item.answer}")
47    while True:
48        reply = input("  思い出せたか? [y/n]: ").strip().lower()
49        if reply in ("y", "n"):
50            return reply == "y"

54    """items を順に出題し、思い出せなかった問題のリストを返す。"""
55    missed: list[Question] = []
56    for number, item in enumerate(items, start=1):
57        if not ask(item, number, len(items)):
58            missed.append(item)
59    return missed

79            round_number += 1
80            print(f"\n--- 思い出せなかった {len(missed)} 問をもう一度出題する（{round_number} 周目）---")

82    except (EOFError, KeyboardInterrupt):
83        print("\n中断した。")
84        return

コード 32 interleave_plan.py
 1"""複数の学習項目から、交互学習の計画表を作成する。
 2
 3項目ごとの問題数を与えると、同じ項目ができるだけ連続しないように並べ、
 41 日あたりの問題数で区切った計画表を出力する。比較のため、項目ごとにまとめて
 5解くブロック学習の順序も表示する。
 6
 7使い方:
 8    py interleave_plan.py Python=6 SQL=4 正規表現=4
 9    py interleave_plan.py Python=6 SQL=4 正規表現=4 --per-day 5
10"""
11
12from __future__ import annotations
13
14import argparse
15from dataclasses import dataclass
16
17
18@dataclass
19class Topic:
20    """学習項目と、残りの問題数。"""
21
22    name: str
23    remaining: int
24
25
26def parse_topic(text: str) -> Topic:
27    """「項目名=問題数」の形式の文字列を Topic に変換する。"""
28    name, sep, count = text.partition("=")
29    if not sep or not name or not count.isdigit() or int(count) <= 0:
30        raise argparse.ArgumentTypeError(f"「項目名=問題数」の形式で指定する: {text}")
31    return Topic(name, int(count))
32
33
34def blocked_order(topics: list[Topic]) -> list[str]:
35    """項目ごとにまとめて解く順序（ブロック学習）を返す。"""
36    return [topic.name for topic in topics for _ in range(topic.remaining)]
37
38
39def interleaved_order(topics: list[Topic]) -> list[str]:
40    """同じ項目ができるだけ連続しない順序（交互学習）を返す。
41
42    毎回、直前と異なる項目のうち残りの問題数が最も多いものを選ぶ。
43    残りの問題数が多い項目を先に減らすことで、終盤に同じ項目が続くのを防ぐ。
44    """
45    pool = [Topic(t.name, t.remaining) for t in topics]
46    order: list[str] = []
47    previous = ""
48    while any(t.remaining > 0 for t in pool):
49        candidates = [t for t in pool if t.remaining > 0 and t.name != previous]
50        if not candidates:
51            # 残りが 1 項目だけになった場合は連続を避けられない。
52            candidates = [t for t in pool if t.remaining > 0]
53        chosen = max(candidates, key=lambda t: t.remaining)
54        chosen.remaining -= 1
55        order.append(chosen.name)
56        previous = chosen.name
57    return order
58
59
60def split_by_day(order: list[str], per_day: int) -> list[list[str]]:
61    """順序を 1 日あたり per_day 問ずつに区切る。"""
62    return [order[i:i + per_day] for i in range(0, len(order), per_day)]
63
64
65def count_repeats(order: list[str]) -> int:
66    """同じ項目が直前と連続した回数を返す。"""
67    return sum(1 for a, b in zip(order, order[1:]) if a == b)

  2
  3CSV の形式（1 行目は見出し）:

  8    topic: 学習した項目
  9    minutes: 学習時間（分）

 40@dataclass(frozen=True)
 41class Record:
 42    """学習ログの 1 行。"""
 43
 44    date: datetime.date
 45    topic: str
 46    minutes: int
 47    method: str

 49
 50def load_records(path: pathlib.Path) -> list[Record]:
 51    """CSV ファイルから学習ログを読み込む。"""
 52    with path.open(encoding="utf-8", newline="") as f:
 53        reader = csv.DictReader(f)
 54        return [
 55            Record(
 56                date=datetime.date.fromisoformat(row["date"]),
 57                topic=row["topic"],
 58                minutes=int(row["minutes"]),
 59                method=row["method"],
 60            )
 61            for row in reader
 62        ]
 63
 64
 65def total_by(records: list[Record], key: str) -> dict[str, int]:
 66    """key（"topic" または "method"）ごとの合計時間を、多い順に返す。"""
 67    totals: dict[str, int] = defaultdict(int)
 68    for record in records:
 69        totals[getattr(record, key)] += record.minutes
 70    return dict(sorted(totals.items(), key=lambda item: item[1], reverse=True))
 71
 72
 73def week_start(day: datetime.date) -> datetime.date:
 74    """day を含む週の月曜日を返す。"""
 75    return day - datetime.timedelta(days=day.weekday())
 76
 77
 78def weekly_minutes(records: list[Record]) -> dict[datetime.date, int]:
 79    """週（月曜日の日付）ごとの合計時間を、日付順に返す。"""
 80    totals: dict[datetime.date, int] = defaultdict(int)
 81    for record in records:
 82        totals[week_start(record.date)] += record.minutes
 83    return dict(sorted(totals.items()))
 84
 85
 86def pad(text: str, width: int) -> str:
 87    """全角文字を半角 2 文字分と数えて、表示幅が width になるまで右側を空白で埋める。"""
 88    display_width = sum(2 if unicodedata.east_asian_width(c) in "WF" else 1 for c in text)
 89    return text + " " * max(0, width - display_width)
 90
 91
 92def print_totals(title: str, totals: dict[str, int]) -> None:
 93    """合計時間と割合を表示する。"""
 94    whole = sum(totals.values())
 95    print(f"## {title}")
 96    for name, minutes in totals.items():
 97        print(f"  {pad(name, 10)} {minutes:>5} 分 ({minutes / whole:>5.1%})")
 98    print()

101def save_weekly_chart(weekly: dict[datetime.date, int], path: pathlib.Path) -> None:
102    """週ごとの学習時間を棒グラフにして保存する。"""
103    labels = [day.strftime("%m-%d") for day in weekly]
104    hours = [minutes / 60 for minutes in weekly.values()]
105    fig, ax = plt.subplots(figsize=(7.0, 3.5))
106    ax.bar(labels, hours)
107    ax.set_xlabel("week (starting Monday)")
108    ax.set_ylabel("hours")
109    ax.grid(True, axis="y", alpha=0.3)
110    fig.tight_layout()
111    fig.savefig(path, dpi=100)
112    plt.close(fig)

117    parser.add_argument("file", type=pathlib.Path, nargs="?", default=DEFAULT_FILE, help="学習ログの CSV ファイル")
118    args = parser.parse_args()
119

124
